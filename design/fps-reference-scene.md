# FPS 参考场景图分析 —— MirrorUnityFPS 验收效果图 `1.webp`

> 用途：作为后续**精确复刻场景布局**的唯一依据。本场景为 Unity **网格块体（blockout/grid）占位风格**的 FPS 测试关卡，无真实贴图，全部由带网格线的立方体拼成。
> 依据图像：`replica_projects/MirrorUnityFPS/验收效果图/1.webp`（约 1120×745，移动端竖屏 UI 叠层）。

---

## 0. 一句话结论

一个**立在蓝色平面地面上的大型灰色"L 形墙体 + 外挂大台阶"主体建筑**，左前方与右侧散布若干**棕褐色箱体掩体**；明亮白昼、冷色调、顶部微俯视的 3/4 视角；除建筑外没有敌人/武器/植被，只有几个棕色方块与一块白色斜坡板。

---

## 1. 场景布局（结构与排列）

整体是**一块开阔的蓝色正方形场地**，中心偏中上部耸立**1 个主体建筑**，四周点缀**数块棕色箱体**。可拆成三组：

### 1.1 主体建筑（画面中央偏左上，约占据上半部）
- 由**两面相连的墙**组成，呈**近似 L 形 / 阶梯形**轮廓：
  - **前墙（较低、面朝镜头）**：位于画面中左侧，宽约整图 1/3，顶部有**一个矩形缺口（notch）**。
  - **后翼墙（较高，偏右）**：位于前墙右后方、更靠里，是全场**最高**的结构。
  - 在后翼墙正面/侧面**外挂一座宽阔大台阶**，从右下地面一路爬升到后翼墙顶。
- 台阶底部的正前方地面上，横放**一块浅白色扁平斜坡板（ramp/木板）**。

### 1.2 棕色箱体掩体群（共约 5~6 块，均为深棕褐色立方体）
- **左远角**：一小块低矮棕箱（画面左边缘，距离最远、最小）。
- **左中前景**：一组高矮不一的棕箱，构成一道**近景掩体/矮墙**（画面左中，尺寸较大，位于建筑左前方）。
- **右侧前景**：一块中等棕箱（画面右下）。
- **建筑顶部**：一小块棕箱（坐在后翼墙顶部右角 / 台阶平台上）。

### 1.3 地面
- 全部为**单一蓝色平面**，铺满整个下半部，与建筑/掩体形成强烈鲜蓝—灰对比。
- 靠近相机底部左侧有一条**细长浅色横条带**（可能是不同高度的地面板块或边缘线）。

> **几何归纳**：这是一个**对称感很弱的开放型掩体场**（非封闭围墙/街区/街道）。核心是"一栋带台阶的大楼 + 散点棕色掩体"。

---

## 2. 建筑外观

### 2.1 主体建筑（灰色）
- **颜色（RGB 近似）**：受光面 `约 (150,155,165)` 冷调浅灰；背光/阴影面 `约 (108,112,120)` 略偏蓝的深灰。
- **材质**：Unity 默认 Standard 材质，无贴图，表面覆**细密网格线**（每面被等分成若干小格，营造"网格体块"质感）。
- **尺寸比例（相对地面立方体=1 格）**：
  - 前墙高约 **8~10 格**，顶带缺口（缺口宽约 2 格、深约 1~2 格）。
  - 后翼墙高约 **10~12 格**，为全场最高点。
- **墙面特征**：
  - 前墙左下方有一个**大门矩形开口**（宽约 3 格、高约 3 格，近似方形过洞），可**透视到后方蓝色地面/天空**，为**通透的过道门洞**（非实心窗）。
  - 除门洞与顶部缺口的"阶梯状"轮廓外，墙面平整、无窗框、无装饰。

### 2.2 大台阶
- 位于后翼墙正面/右侧，**约 10~12 级**，从右下地面升至后翼墙顶。
- 每级为灰色块体，**踏面带有深色阴影缝**，从而形成明显的一级级"阶梯纹理"。
- 台阶底部与平地交界处，铺**一块浅白/近灰的扁平板**（`约 (230,232,238)`），像斜坡/门板前的小坡道。

### 2.3 棕箱掩体
- **颜色（RGB 近似）**：主色 `约 (130,95,45)~ (150,112,55)` 芥末/深橄榄棕；受光顶面略亮，侧面略暗。
- **尺寸**：远角低箱约 **1~2 格**高；左中近景箱约 **2~3 格**高（做掩体矮墙）；右侧箱约 **2 格**；建筑顶箱约 **1.5~2 格**。
- 表面同样覆细网格线，纯立方体、无门窗。

---

## 3. 地面与天空、光照

### 3.1 地面
- **颜色（RGB 近似）**：`约 (65,155,210)` 饱和的天蓝/湖蓝，全图最抢眼的色块。
- **材质/纹理**：单一平面，带**轻微网格线**，无草地/沥青/砖石等写实纹理，纯色块广场。

### 3.2 天空
- **渐变**：顶部为**深海军蓝** `约 (35,70,135)`，向地平线渐亮为**浅青蓝** `约 (150,200,235)`。
- 无云，**晴朗**天空。

### 3.3 光照
- **类型**：清晰**方向光（平行光）**，白昼，明亮清冷。
- **方向**：大致来自**左上方/镜头前方**（墙体朝向镜头面、台阶侧面受光，背侧面偏暗）。地面与箱体下方有**柔和投影**（地面呈现略暗的蓝色投影块）。
- **色调**：冷色为主，**非傍晚、非阴天**，接近干净的晴天。

---

## 4. 相机视角

- **类型**：**3/4 俯视的透视预览视角**，略高于玩家身高的**中等高度**，非第一人称、也非正俯视。
- **朝向**：镜头大致面向建筑（看向画面右上方的主体），视野较宽，能同时看到开阔地面 + 建筑全貌 + 前景掩体。
- **高度**：处于地面之上、约玩家站立视线附近并**轻微下俯**，因此既能看清地面平面，又能看到建筑立面与台阶侧面。
- 画面叠层为**移动端 UI**：左下角**十字型虚拟摇杆**（四向箭头圆形按钮）；右下角三枚圆形按钮——**"眼睛"(视角轮换)** + **两个"奔跑/冲刺"小人**，表明这是**移动端竖屏 FPS 测试场景**。

## 5. 其他可见元素

- **玩家/敌人/武器**：**无**。画面中没有任何角色、枪械、准星。
- **道具**：除上述棕箱 + 白色斜坡板外，无路牌、无植被、无载具。
- **UI 叠层**：仅为测试用移动端控件（摇杆 + 眼睛/奔跑按钮），不属于场景内容，复刻时**不建模**。
- **唯一地面异物**：建筑台阶前的**白色斜坡板**（可视作可走上去的坡道/装饰）。

## 6. 复刻要点清单（可操作）

1. **地面**：一整块蓝色方形平面（`#41 9B D2` 附近的 #, 即 RGB≈(65,155,210)），表面附网格线，作为唯一基础地面。
2. **主体建筑（灰，RGB≈(150,155,165)）**：
   - 前墙：高约 8~10 格，顶部中央留 2 格宽缺口；左下开 3×3 通透门洞。
   - 后翼墙：高约 10~12 格，位于前墙右后方，为最高点。
   - 大台阶：后翼墙外挂约 10~12 级，踏面带阴影缝；底部铺白色斜坡板。
3. **棕箱掩体（RGB≈(130,95,45)）**：左远 1 小箱、左中 1 组高矮箱（近景掩体墙）、右侧 1 箱、建筑顶 1 箱。
4. **材质**：全部面片使用**带细网格线**的单色材质，无真实贴图。
5. **光照**：左上方向光、冷色晴空白昼、地面投射柔和阴影。
6. **相机**：中高度、轻下俯、宽视场的 3/4 透视预览视角（复刻时用该机位即可还原画面）。移动端 UI 仅为验收叠层，**不进入场景**。

> **量化坐标建议（以地面 1 格为单位，相对画面）**：建筑前墙中心约位于场地上部中左（约 25%~45% 宽度带），台阶在后翼墙正面偏右下，棕箱按上文"左远/左中/右/顶"四处摆放，地面铺满全场。
