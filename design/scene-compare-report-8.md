### 1.3 板条箱：数量 / 位置 / 颜色（橄榄棕 + 金）

- **参考图**：约 **4 个**橄榄棕×金色箱体——左前 **L 形/双层堆**、**远左小箱**、**右侧建筑基座箱**、**屋顶金色小箱**。
- **当前实现**：当前帧**仅见**：
  - 左下：一块**深灰色方块**（悬空/贴墙，非橄榄棕）；
  - 中下：一块**小灰蓝方块**；
  - 右上：**金褐色烟囱**（可视为屋顶金箱）。
  - **未见橄榄棕主体×金色镶边的板条箱堆**，左侧远箱、右侧基座箱均不在画面内（或未建模）。
- **结论：✗ 数量/位置/颜色均不符。** 即使把烟囱算作屋顶金箱，也缺左侧与右侧的橄榄棕箱堆；当前左下是一块深灰方块，颜色随参考图「橄榄棕×金」对不上。

### 1.4 平台：是否单块亮蓝

- **参考图**：**一整块连续亮蓝瓷砖平台**（约 `(85,160,205)`，带护边）。
- **当前实现**：底部为**一种青蓝色 (cyan) 平面**，色调**偏青/偏绿**（约 `(110,215,235)` 级），且当前帧只见**底部一条细带 + 左下楔形**，**看不到完整平台范围**，无法确认是否为连续一整块。
- **结论：△ 部分符合**。是单块亮蓝（无分割），但**色相偏青**（应更接近天空蓝 `(85,160,205)`，R 通道应明显低于 B），且平台完整性因取景无法核验。

### 1.5 天空：深蓝渐变

- **参考图**：天顶深海军蓝 `(40,62,98)` → 地平线浅蓝 `(68,100,147)`，无云。
- **当前实现**：**深蓝渐变存在**——顶部深海军蓝 → 中部一条较浅蓝 → 底部偏青。**方向正确**。
- **结论：✓（近似，偏亮）**。主要偏差：底部多了一段**青色（cyan）**过渡，参考图到地平线是偏蓝的浅蓝 `(68,100,147)`，不是青色；整体略偏亮。

### 1.6 相机视角：3/4 低角度？建筑/平台/天空占比

- **参考图**：**3/4 低角度广角全景**——地面占底部约 60%、天空占顶部约 40%，建筑+大台阶+箱体+平台全可见。
- **当前实现**：**近距特写/中景**，相机贴近建筑：
  - 建筑占画面**绝对主体**（约 55~70%），天空占顶部约 25~30%，平台仅底部**细条**（约 5~8%）。
  - **看不到平台全貌、大台阶、拱门、箱体分布**——非参考图那种能同时看到「地面+建筑+台阶+箱体+天空」的 3/4 低角度全景。
- **结论：✗ 取景不符**。这是本轮**最大的问题**：即使几何/材质正确，镜头这么近也无法完成全景级验收比对。

## 3. 问题清单（按严重度排序）

**高严重度（决定成败）**
1. **取景错误（首要）**：当前 `scene_verify.png` 是**近距特写**，无法同时看到平台、大台阶、拱门、箱体分布、天空占比。复现：直接查看图片，建筑占画面 55~70%，平台仅底部细条。**建议**：把相机拉远到参考图那种 3/4 低角度**广角全景**，地平线约在画面 40% 高度，让「地面+建筑+台阶+箱体+天空」同框。
2. **板条箱缺失/错色**：当前帧无橄榄棕×金板条箱堆；左下是**深灰色方块**、中下是灰蓝小方块。**建议**：按参考图放置约 4 个箱体（左前 L 形堆、远左小箱、右侧基座箱、屋顶金箱），主色橄榄棕 `(78,66,38)`、金边 `(172,138,71)`。

**中严重度（形态/材质）**
3. **右楼过白、缺网格砖纹**：右楼近白 `(215,222,232)`，且整体为光滑纯色，无参考图的细密网格砖纹。**建议**：整组建筑改回更饱和的蓝灰石板色（受光约 `(120,150,180)~'(150,180,205)`、阴影约 `(80,105,140)`），并叠加网格线纹理。
4. **拱门 / 大台阶不可见**：可能是被裁切（取景问题），也可能未建模。**建议**：先修正取景，若仍不可见则需补齐左塔**拱形门洞（透视天空）**与右楼**外挂大台阶**。
5. **平台色偏青**：`(110,215,235)` 偏青。**建议**：改为天空蓝 `(85,160,205)`，R 通道明显低于 B。

**低严重度（微调）**
6. 金色烟囱位置在楼体**左上**，参考在**右上**；且尺寸偏小。建议右移并适当放大。
7. 天空底部**青色调**过强，参考图到地平线是偏蓝浅蓝（非青）。建议把底部过渡色改为 `(68,100,147)` 级。

## 4. 总体结论

**有条件通过（Direction Correct，但构图仍不合格）。**

- **进步**：建筑已从红色改为**蓝灰**，天空已改为**深蓝渐变**，平台为单块亮蓝——主基调方向正确，且远好于第七次。
- **未达标**：① 取景仍为**近距特写**，无法做全景级布局比对；② **拱门/大台阶**不可见；③ **板条箱**（橄榄棕×金）缺失/错色；④ 右楼**过白**、整体**无网格砖纹**、平台**偏青**。

**建议主 agent 下一轮优先**：
1. 先把相机拉到 **3/4 低角度广角全景**（地平线约 40% 高度、地面+建筑+台阶+箱体+天空同框）；
2. 补齐并校正**板条箱**（橄榄棕×金，约 4 个，左前堆/远左/右基座/屋顶）；
3. 建筑整体改回**更饱和蓝灰**并加**网格砖纹**，右楼不要过白；
4. 平台色从青色改为**天空蓝 `(85,160,205)`**；
5. 修正**金色烟囱**位置（右上）。

然后在同机位重新出图，进入第九次对比。
