# 场景七次验收对比报告（QA · 多模态视觉核验）

- **任务书**：场景七次验收对比（参考图 vs 当前实现）
- **参考图**：`replica_projects/MirrorUnityFPS/验收效果图/1.webp`（1950×1300）
- **当前实现**：`scene_verify.png`（1280×720）
- **核验方式**：read 直读两图 + 局部裁剪放大核对 + 逐像素取样（Pillow 中位数/亮部均值）
- **时间**：2026-08-31

> 关键结论前置：**参考图是一张"像素/体素风"（blocky / low-poly）建筑场景图**，不是自然风景图。
> 因此本报告以**可量化的 RGB 值 + 布局描述**为准，并明确标注与当前实现的**实质差异**。

## 0. 一句话总述

参考图 `1.webp` = **蓝灰石板色双塔建筑（含大台阶）+ 橄榄棕/金色板条箱 + 一整块亮蓝瓷砖地面 + 深蓝渐变天空**。
**参考图中没有树**（绿色植被像素占比 ≈ 0.0001，可视为 0）；**建筑是蓝灰，不是红色**；**地面是连续的一块亮蓝平台，未见明显切成 4 块**。

## 1. 建筑的确切颜色（RGB 近似值）

建筑是 **蓝灰 / 石板灰（slate blue-gray）**，不是红色，也不是棕色。由于体素贴图 + 受光面/背光面差异，不同立面亮度不同，但色相统一为**低饱和蓝灰色**。

| 部位 | 取样区域(px) | 近似 RGB |
|---|---|---|
| 左塔正面（受光） | (560,650)-(800,820) | `(96,139,175)` |
| 左塔正面（亮部均值 p85） | 同上 | `(131,174,202)` |
| 左塔侧/背光面 | (320,520)-(470,760) | `(78,112,157)` |
| 左塔最暗砖格 | (300,560)-(480,760) | `(80,100,120)` |
| 右楼受光墙面 | (1400,470)-(1650,620) | `(121,141,158)` / 亮部 `(181,203,218)` |
| 右楼背光面 | (1200,400)-(1360,560) | `(82,102,123)` |

| 门洞内阴影 | (640,470)-(820,580) | `(81,99,118)` |

**给材质的建议基准色（亮面）**：约 `(120,150,180) ~ (150,180,205)`；**阴影面**约 `(80,105,140)`。
即：**蓝灰**（B 分量为最大通道，R 为最小），绝非当前的 `(255,40,40)` 红色。

- 确认：**建筑 = 蓝灰（slate blue）**；灰白台阶、浅色受光楼体为同色系提亮。

## 8. 问题清单（按严重度排序）

**高严重度（原则性错误）**
1. **建筑材质颜色错误**：参考为蓝灰石板色，当前实现为纯红 `(255,40,40)`。复现：直接查看 `scene_verify.png` 中央红墙。应改用约 `(120,150,180)~`(150,180,205)` 亮面 / `(80,105,140)` 阴影面。
2. **参考图不含"树"元素**：当前实现含树，属参考图没有的多余内容。复现：无头/画面扫描，绿色占比≈0。
3. **天空配色错误**：参考为深蓝天顶→浅蓝地平线，当前实现在顶部呈红色，天空基调错误。

**中严重度（布局/结构不一致）**
4. **平台结构不符**：参考图是**一整块连续亮蓝瓷砖平台**（带护边），未见 4 块分离 base 平台；当前实现若为 4 块分离平台则布局对不上。
5. **物件排布不符**：参考图是**围绕建筑基座集中摆放的箱体**（左前堆 + 右侧基座 + 屋顶烟囱箱），不是随机散生自然元素。
6. **建筑形态差异**：参考图为**双塔+城垛凹口+拱门+大台阶**的体素建筑群；需确认当前建筑是否具备这些特征。

**低严重度（比对证据不足）**
7. **当前截图取景不当**：`scene_verify.png` 是贴到建筑墙角的特写，无法与参考全景做布局级对比。建议重新生成一张与参考视角一致（3/4 低角度全景、地平线约 40% 高度、含地面与天空）的整景截图再比对。

---

## 9. 总体结论

**不通过（✗）。**

核心原因：
- 参考图为**蓝灰建筑 + 橄榄/金箱体 + 亮蓝单平台 + 深蓝渐变天空**的体素风静景，且**无树**；
- 当前实现为**红色建筑 + 树 +（疑似多块）蓝色平台 + 红色天空**，且当前截图仅为墙面特写、全局不可比。

**建议主 agent**：先修正材质与场景基调（建筑→蓝灰、天空→深蓝/浅蓝渐变、地面→单块亮蓝瓷砖、去掉或重定义"树"元素），再生成一张与参考图取景一致的整景截图，重新走第七次视觉比对。
